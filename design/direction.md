## 재생 화면 그림 자리 (2026-11-12 결정)
- 그림 대신 곡 분위기에 맞는 자동 그라데이션 배경 + 실시간 가사
- 가사·싱크 (확정: 자동이 기본, 실패한 곡만 수동): LRCLIB(무료, 시간 붙은 LRC) 자동 조회가 기본. 찬양곡도 꽤 있음(피아워십 4/4, 마커스워십 12/13)
  - 유튜브 라이브 버전과 시간이 다를 수 있음 → 곡 길이로 버전 고르기 + 화면에서 오프셋 조절
  - 없는 곡: 수동 싱크(재생하며 줄마다 탭), 가사 글은 가사 사진에서 추출
- 분위기 색: 가사 내용으로 한 번 판단해 저장, 사용자가 바꿀 수 있게

## 화면 구성 초안 (2026-11-12)
- 디자인 초안 캔버스: https://claude.ai/artifact/HdBVBQXQiF2ZetZi6ZWHCy (비공개)
- 재생 화면을 펼치면 전체 화면, 접으면 아래 탭 바 위에 미니 플레이어
- 탭 4개: 콘티(이번 주 순서·인도자 메모) / 라이브러리(검색·분류·내 목록) / 묵상(가사 줄 골라 메모) / 연습(추천: 구간 반복, 속도, 연습 기록)
- 목록 만들기: 라이브러리 안 "내 목록"의 첫 칸 "새 목록 만들기". 콘티는 관리자가 라이브러리에서 곡을 골라 만드는 특별한 목록
- 설정·사용자 관리·사용법: 콘티 화면 오른쪽 위 사람 아이콘
- 하단 바: 떠 있는 유리 알약 두 개(미니 플레이어 + 탭 바). 선택된 탭은 탭별 색 알약이 미끄러져 옴(콘티 남색, 라이브러리 청록, 묵상 장미, 연습 호박). 탭 화면은 옆으로 밀어서 넘김, 넘기는 동안 알약이 손가락을 따라감. 움직임 줄이기 설정이면 애니메이션 끔
- 목록 만들기 입구: 라이브러리 "내 목록" 첫 칸(기본) + 곡 옆 ⋯ "목록에 담기"(창 안에 + 새 목록) + 길게 눌러 여러 곡 담기. 콘티는 목록에 "이번 주 콘티로 지정"(관리자). 봇으로 추가한 곡은 라이브러리로
