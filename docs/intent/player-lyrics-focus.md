# 플레이어: 한 화면 맞춤 + 가사 집중 모드

확정: 2026-11-21 (아티팩트 댓글 스레드 e939b339 + 채팅 인터뷰)

## 목표
- 플레이어를 열면 지금 구성(가운데 가사, 제목, 재생 바, 조작 버튼)이 한 화면 안에 다 보인다. 지금은 비율이 안 맞아 조작부가 아래로 잘려 있다.
- 스크롤을 살짝 내리면 가운데 가사 영역이 커지고, 아래 조작부는 재생 버튼만 남긴 작은 줄로 줄어든다(가사 집중 모드).
- 스크롤을 살짝 올리면 원래 화면으로 돌아온다.
- 내릴 때와 올릴 때 모두 두 상태 중 하나로 '탁' 맞춰지고(중간에 멈추지 않음), 그때 "도로록" 햅틱이 온다.

- 다른 탭 건드리기
