# 처음 온 사람을 위한 인터랙티브 사용법 가이드

확정: 2026-11-26

## 목표

- 앱을 처음 열면 실제 화면 위에 말풍선 투어가 떠요. 사용자는 말풍선을 따라 직접 누르며 배워요.
  1. 곡 듣기
  2. 플리에 곡 담기
  3. 봇 채팅에 유튜브 링크를 보내 곡 추가하기
  4. 묵상, 연습, 랭킹 탭을 한 줄씩 소개하기
- 플리 이름 옆에 **"공유 중"** 표시를 붙여요.
- 가이드 안에 아래 문장을 그대로 넣어요.
  > "**공유 중** 표시가 붙은 플리는 모두에게 공유됩니다. 내가 다운로드한 곡은 나만 볼 수 있어요."
- 대상: 앱을 처음 쓰는 찬양팀원과 교인
- 이유: 사용법을 몰라서 앱 쓰기를 꺼린다는 이야기가 나왔어요.
- 완료 기준: 처음 온 사람이 설명을 듣지 않고 아래 네 가지를 해낼 수 있어요.
  - 곡을 재생해요.
  - 곡을 플리에 담아요.
  - 봇에 링크를 보내요.
  - 다른 탭이 무엇을 하는 곳인지 알아요.
- 조건:
  - 투어는 처음 한 번만 자동으로 떠요.
  - 언제든 건너뛸 수 있어요.
  - 설정의 "사용법 다시 보기"를 누르면 다시 볼 수 있어요.

## 하지 않을 것

- 공유 기능은 다시 설계하지 않아요. 멤버가 공유하는 기능이나 곡 하나만 공유하는 기능은 나중에 따로 해요.
- 랭킹, 재생 횟수, 서버 API(`loopbot-api`)는 바꾸지 않아요.
- 묵상, 연습, 랭킹 탭은 따라 하는 단계까지 만들지 않고 소개만 해요.

## 참고: 지금 공유가 동작하는 방식 (코드 기준)

- 곡 하나가 아니라 플레이리스트 단위로 공유해요.
- 공유는 관리자만 켜고 끌 수 있어요. 플리 메뉴의 "공유 켜기/끄기"로 해요.
- 멤버는 공유된 플리를 바꿀 수 없어요. 그 안의 곡을 자기 플리로 담는 것만 돼요.
- 봇에 보낸 곡은 보낸 사람의 플리에 들어가요.
